# Master Thesis in Robotics, Cognition, Intelligence

This thesis develops a cross-embodiment skill discovery system that learns embodiment-invariant skill across four different robots (KUKA iiwa, Franka panda, Sawyer, and Ur5e) and across multiple tasks. 
These learned skills are then used for downstream behavior cloning with a transformer-based diffusion policy. A more detailed description of the two components will be presented next.
